# Windows 照片深度去重与智能年月归档工具

这是一个基于 Go 语言开发的高性能照片去重与整理程序，具备极快的文件 I/O 速度，并可通过 GitHub Actions 在云端一键自动打包生成 Windows 单文件 `.exe`。

---

## 核心特性

1. **第一类：完全重复（同名同大小）**
   * 自动去重，保留一份母本。
   * 优先提取照片 Exif 原始拍摄时间（无 Exif 则读取文件时间），自动建立 `年/月/` 文件夹（例如 `2022年/9月/`）归档保存。
   * 重复副本直接跳过，并在报告中统计节省的空间。

2. **第二类：同名不同大小**
   * 单独归集到 `人工筛选_同名不同大小/`，自动保留原始文件名与大小标识，方便人工双击比对画质。

3. **第三类：同大小不同名**
   * 单独归集到 `人工筛选_同大小不同名/` 集中等待人工确认是否为重命名副本。

4. **安全模式**
   * 采用“复制”模式，原照片保持原样不动，绝不误删。

## 如何在 GitHub 上自动生成 exe？

1. **新建仓库**：在 GitHub 上创建一个新的仓库（公开或私有均可，例如 `photo-deduplicator`）。
2. **上传项目文件**：将本项目解压后的所有文件（包括隐藏文件夹 `.github`）上传或推送（`git push`）到该仓库的 `main` 分支。
3. **自动开始编译**：代码上传后，点击仓库顶部的 **Actions** 标签页，GitHub Actions 会自动启动 Windows 虚拟机进行编译，约 15 秒完成。
4. **下载 EXE**：编译完成后，点击该次运行记录，在页面底部的 **Artifacts** 区域即可下载打包好的 `PhotoDeduplicator-Windows.zip`，解压即得 `PhotoDeduplicator.exe`！

## Windows 本地使用方法

1. 双击运行 `PhotoDeduplicator.exe`。
2. 按照屏幕提示，直接将待整理的照片文件夹拖入黑框窗口，按回车。
3. 输入整理后要存放的目标文件夹，按回车。
4. 程序会瞬间完成扫描、分类与年月归档，并在目标文件夹内生成一份完整的《去重与归档统计报告.txt》。
