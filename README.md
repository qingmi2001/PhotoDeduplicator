# Windows 照片深度去重与智能年月归档工具 (GUI 窗口版)

这是一个专为 Windows 设计的高颜值、高性能图形界面 (GUI) 照片去重与整理程序。已配置 GitHub Actions 自动编译并**直接发布到 GitHub Releases** 供一键下载。

---

## 核心特性

1. **图形界面操作**：
   * **多源文件夹选择**：支持通过按钮添加多个不同盘符或层级的照片文件夹，亦可直接将文件夹**批量拖拽**进列表。
   * **单目标文件夹**：一键指定整理后归档的主目录。
   * **后台多线程处理**：大批量（数万张）照片扫描与复制过程中界面流畅不卡死，带有实时进度条和详细日志输出。

2. **去重与归类规则**：
   * **第一类：完全重复（同名且同大小）** -> 自动去重，保留一份母本，优先提取 Exif 原始拍摄日期按 `2022年/9月/` 目录分层归档，多余副本跳过并统计省下的磁盘容量。
   * **第二类：同名不同大小** -> 单独存入 `人工筛选_同名不同大小/`，自动带上字节大小标识，方便人工双击对比画质。
   * **第三类：同大小不同名** -> 单独存入 `人工筛选_同大小不同名/`，集中方便人工甄别。
   * **正常照片** -> 同第一类母本一样，规范按“年/月”分层归档。
   * **安全第一** -> 仅复制，绝不删除原文件。

## 如何通过 GitHub 自动编译并发布到 Releases？

1. **新建 GitHub 仓库**：在 GitHub 上新建一个仓库（如 `photo-deduplicator-gui`）。
2. **上传项目文件**：将解压后的所有文件（包含 `.github` 目录）上传或推送（`git push`）到仓库的 `main` 分支。
3. **自动发布到 Releases**：
   * 代码上传后，GitHub Actions 会自动触发编译。
   * 编译完成后，会自动在你的 GitHub 仓库主页右侧的 **Releases** 区域创建最新的发布版本（例如 `v1.0.1`）。
   * 打开 **Releases** 页面，在 **Assets** 列表里即可直接点击下载 **`PhotoDeduplicatorGUI.exe`**，随时随地分享和使用！
