# Windows 全文件与照片深度去重归档工具 (专业双核版)

这是一个专为 Windows 设计的高性能图形界面 (GUI) 文件与照片去重整理程序，内置**专业级冲突文件并排对比审查工具**。已配置 GitHub Actions 自动编译并**直接发布到 GitHub Releases** 供一键下载。

---

## 核心特性

1. **专业级「并排对比审查」窗口 (新增)**：
   * 自动汇集所有第二类（同名不同大小）与第三类（同大小不同名）冲突文件。
   * **并排双窗口实时渲染**：左侧与右侧并排展示图像缩略图、长宽像素分辨率、具体字节大小、Exif/修改时间。
   * **一键极速决断**：
     * 点击「保留此文件」即可将另一份副本**安全移至专门的 `已排除的弃用副本/` 目录**（绝不永久抹除，给后悔留后路）。
     * 提供「两者均保留」与「在资源管理器中打开」辅助操作。
     * 支持键盘上一组/下一组快速翻页比对。

2. **全文件与自定义格式扩展**：
   * 📷 **仅照片与视频（默认预设）**：自动抓取常见照片与视频格式。
   * 🌐 **全部文件 (*.*)**：无视后缀，对文档、表格、压缩包、安装包等所有文件通用去重归档。
   * ⚙️ **指定后缀过滤**：支持自定义输入特定后缀（如 `.pdf, .docx, .xlsx, .zip`）。

3. **智能日期归档策略**：
   * 照片与视频：优先提取内嵌的 **Exif 真实拍摄时间**（老照片时间不乱）。
   * 普通文档与文件：以 **修改时间（LastWriteTime）** 为基准建立 `年/月/` 目录归档，真实还原最后编辑归档历史。

4. **图形界面操作与智能防爆仓**：
   * **多源文件夹选择**：支持通过按钮添加多个不同盘符或层级的文件夹，支持直接**批量拖拽**进列表。
   * **单目标文件夹与磁盘容量感知**：选定目标文件夹时，界面**实时显示目标磁盘当前剩余可用空间与总容量**。
   * **智能防爆仓预警机制**：在开始复制前，程序自动汇总待整理文件的总容量与目标盘剩余空间对比。如果剩余空间不足，**自动弹出强警告窗口拦截**，避免把目标磁盘撑爆卡死。
   * **后台多线程处理**：大批量文件扫描与复制过程中界面流畅不卡顿，带有实时进度条和详细日志输出。

5. **去重与归类规则**：
   * **第一类：完全重复（同名且同大小）** -> 自动去重，保留一份母本按 `年/月/` 目录分层归档，多余副本跳过并统计省下的磁盘容量。
   * **第二类：同名不同大小** -> 单独存入 `人工筛选_同名不同大小/`，自动带上字节大小标识，方便人工双击对比版本与画质。
   * **第三类：同大小不同名** -> 单独存入 `人工筛选_同大小不同名/`，集中方便人工甄别。
   * **正常文件** -> 同第一类母本一样，规范按“年/月”分层归档。
   * **安全第一** -> 仅复制，绝不误删原文件。

## 如何通过 GitHub 自动编译并发布到 Releases？

1. **上传项目文件**：将解压后的所有文件（包含 `.github` 目录）上传或推送（`git push`）到 GitHub 仓库的 `main` 分支。
2. **自动发布到 Releases**：
   * 提交代码后，GitHub Actions 会自动触发云端 Windows 编译。
   * 编译完成后，会自动在你的 GitHub 仓库主页右侧的 **Releases** 区域创建最新的发布版本（例如 `v1.0.1`）。
   * 打开 **Releases** 页面，在 **Assets** 列表里即可直接点击下载 **`PhotoDeduplicatorGUI.exe`**！
